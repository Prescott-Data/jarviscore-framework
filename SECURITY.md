# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or Discussions.

Use [GitHub private vulnerability reporting](https://github.com/Prescott-Data/jarviscore-framework/security/advisories/new) to submit a confidential report. If that channel is unavailable, email **info@prescottdata.io** with the subject `SECURITY - brief description`.

Include:

- A description of the vulnerability and its impact
- Affected versions or commit hashes
- Reproduction steps or a proof of concept
- Any known mitigations or suggested fixes

Do not include credentials, tokens, customer data, or other third-party secrets. We will validate the report, coordinate remediation, and discuss disclosure with you before publishing details.

## Supported versions

Security fixes target the latest published JarvisCore release and `main`. Please update to the latest release before reporting a vulnerability that may already have been resolved. Reports affecting older versions are still useful; include the exact version so we can assess impact.
